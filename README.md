# Kyle Alejo | Personal IT Portfolio

A responsive personal portfolio website created for the CC101 and CC102 final task at Our Lady of the Sacred Heart College of Guimba, Inc.

## Website sections

- Home / introduction
- Personal information
- Educational background
- Skills and competencies
- Java project section
- Contact information

## Built with

- HTML5
- CSS3
- JavaScript

## Preview locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub (for example, `kyle-alejo-portfolio`).
2. Upload all project files to the repository's root folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. Your website link will appear in the Pages settings.

## Personalize before publishing

- Replace the email placeholders in `index.html` with your active email address.
- Review your personal and educational details.
- Update the skills to reflect what you can demonstrate.
- Replace the Java code placeholder with your actual CC102 final performance task source code.
- Test the navigation and links on both desktop and mobile.
